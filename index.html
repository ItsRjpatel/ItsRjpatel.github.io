FLAGSHIP ENGINEERING PROJECT

Endpoint Sentinel X

Personal Engineering Project / Enterprise-style Endpoint Management Platform

Designed and engineered a scalable full-stack endpoint management and monitoring platform built to deliver real-time system visibility, automated risk assessment, health telemetry, and real-time command orchestration across enterprise Windows endpoints.

System Architecture & Data Flow
Windows Agent Python Telemetry
↓ REST
FastAPI Backend Async REST & Sockets
↔ Pub/Sub
PostgreSQL + Redis State & Inventory
↔ Sockets
React / TS Console Dashboard UI

Problem & Solution

  • Problem: Enterprise IT operations require real-time visibility into distributed endpoint health, patch posture, hardware specs, and instant remote remediation capabilities without reliance on heavy manual polling.
  • Solution: Engineered a lightweight agent-backend architecture leveraging asynchronous API routes and persistent WebSocket channels for real-time command dispatch and auto-remediation.

Key Implemented Capabilities

  • Hardware & OS Inventory auto-discovery
  • Endpoint Online/Offline health monitoring
  • Real-time performance telemetry (CPU, Memory, Disk)
  • Security risk scoring & automated alert generation
  • Alert auto-resolution workflows
  • Real-time WebSocket command orchestration

Architecture & Tech Stack

  • Backend API: Python & FastAPI (Asynchronous REST + WebSockets)
  • Data Layer: PostgreSQL (Metadata & Inventory) + Redis (Pub/Sub & Heartbeat Cache)
  • Frontend Console: React, TypeScript, TailwindCSS
  • Containerization: Docker & Azure Deployment Ready

Engineering Decisions

  • Chosen FastAPI over Synchronous frameworks for non-blocking WebSocket connection concurrency.
  • Utilized Redis Pub/Sub for decoupled, instant command queuing across distributed worker nodes.
  • Designed modular agent telemetry models to minimize endpoint CPU/RAM footprint.
