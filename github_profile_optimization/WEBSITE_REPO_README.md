---

## ⚡ Technical Highlights & Architecture

- **Vanilla Web Architecture:** Built using clean HTML5, modern Vanilla CSS3 custom design system, and modular JavaScript without heavy frameworks or unnecessary third-party dependencies.
- **Glassmorphism & Rich Aesthetics:** Custom dark theme palette (`#0a0a0f`), subtle gradients, interactive hover micro-animations, particle canvas background, and custom typography (`Outfit`, `Inter`, `JetBrains Mono`).
- **Endpoint Sentinel X Case Study:** Dedicated flagship engineering project showcase detailing microservices architecture, FastAPI backend, WebSockets, Redis Pub/Sub, and interactive visual system flows.
- **Windows Server 2022 Capstone Section:** Featured 2x2 technical evidence highlights and full 10-screenshot categorized evidence gallery (`Active Directory`, `DNS & DHCP`, `Storage & File Shares`, `Admin & Print`, `Backup & Diagnostics`).
- **Interactive Lightbox & Modals:** Accessible full-screen image Lightbox supporting image counters (`1 of 10`), Previous/Next navigation buttons, Left/Right arrow keys (`ArrowLeft` / `ArrowRight`), ESC key close, and backdrop overlay dismiss.
- **Data-Driven Certifications Modal:** Dynamic credential cards prepared for `assets/certifications/` image uploads, supporting verified certifications (Microsoft AZ-900) and Wipro Internal Assessments.
